# Projektelis - AI Agent Instructions

Šios instrukcijos taikomi AI agentams, dirbantiems su šiuo projektu.

## Projekto kontekstas
Prieš atliekant pakeitimus, perskaitykite `context.md` failą.
Visada pirmenybę teikite naujausiam projekto kodui, o ne senesnei dokumentacijai.

## Technologijos
- Naudojama React + Vite[cite: 1].
- Naudojama JavaScript ir JSX.
- Nenaudokite TypeScript, jei to nėra prašoma.
- Nenaudokite Tailwind CSS ar CSS modulių, kol nebuvo prašyta.
- Komponentų stilius palaikykite atskiruose `.css` failuose.
- React komponentus saugokite `src/` aplanke[cite: 3].

## Kodo pakeitimai
- Prieš modifikuodami esamą failą, jį patikrinkite.
- Neišsigalvokite projekto logikos ar API, kurių nėra.
- Išsaugokite esamą funkcionalumą, nebent buvo aiškiai paprašyta jį pakeisti.
- Venkite nesusijusių refaktorizavimų ir nereikalingų priklausomybių.
- Teikite pirmenybę paprastiems sprendimams.
- Naudokite funkcinius React komponentus ir React „hooks“.

## Dizainas
Laikykitės esamo projekto stiliaus:
- Šviesus fonas (pagal dabartinį dizainą).
- Švarus ir minimalistinis modernus UI[cite: 2].
- Responsyvūs (pritaikyti skirtingiems ekranams) išdėstymai.

Nekeiskite bendros dizaino krypties, nebent to prašoma.

## Vartotojo sąsajos (UI) kalba
- Vartotojui matomi tekstai turi būti lietuvių kalba[cite: 2].
- Etiketės ir pranešimai turi būti trumpi bei aiškūs.

## Prieš baigiant darbąy
2. Esamas funkcionalumas vis dar veikia.
3. Nebuvo pridėta nereikalingų priklausomybių.
4. UI išliko responsyvus.
5. Importai ir failų keliai yra teisingi.

## Pakeitimų pristatymas
- Trumpai paaiškinkite, kas pasikeitė.
- Nurodykite kiekvieną pakeistą ar naują failą pagal jo tikslų kelią.
- Jei kodą reikia įklijuoti rankiniu būdu, pateikite pilną atnaujintą failą.
- Aiškiai nurodykite, ar failą reikia sukurti, ar pakeisti.
- Pateikite trumpą būdą, kaip patikrinti rezultatą.
